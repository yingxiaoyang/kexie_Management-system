### GitHub Desktop 使用建议

后续日常操作优先使用 GitHub Desktop：

1. 打开仓库 `kexie_Management-system`。
2. 修改项目文件。
3. 在 `Changes` 查看改动。
4. 在 `Summary` 写清楚本次修改内容。
5. 点击 `Commit to main` 或 `Commit to 当前分支`。
6. 点击 `Push origin` 同步到 GitHub。

多人协作或开始大功能前，建议先新建任务分支。

### 分支规则

`main` 是稳定主分支。

小文档、小配置可以直接提交到 `main`。

大功能、多人协作任务建议使用任务分支，例如：

- `setup/docker-mysql`
- `setup/frontend-existing-cleanup`
- `feature/backend-data-model`
- `feature/submission-review`
- `feature/archive-export`
- `feature/portal-admin-ui`

任务分支完成并确认后，再合并回 `main`。
