# 科研项目材料管理平台任务交接记录

## 2026-08-06：对话 10 - 负责人权限和文件路径加固

## 当前结论

对话 10 已完成。负责人现在只能查看和下载自己负责项目范围内的提交文件与任务模板；管理员继续保留全局访问权限。提交文件、任务模板、导入模板和归档导出包下载均接入统一真实路径校验，数据库中的目录外路径、`..` 越界路径、异常路径和符号链接越界都会被拒绝。

## 已完成

- 新增可复用访问检查工具：
  - 项目访问检查：管理员全局通过；负责人必须是对应项目的 `owner`。
  - 提交记录访问检查：先定位提交所属项目，再复用项目访问检查。
  - 材料任务访问检查：管理员全局通过；负责人必须拥有任务适用范围内的项目，且模板访问只允许 `published` 或 `closed` 任务。
- 修复 `GET /submissions/:id/files`：
  - 返回文件名、大小和类型前先检查负责人是否属于提交对应项目。
- 修复 `GET /submissions/:submissionId/files/:fileId/download`：
  - 下载前检查提交项目归属。
  - 下载前验证真实文件路径位于 `UPLOAD_ROOT`。
- 修复 `GET /material-tasks/:taskId/templates`：
  - 负责人只能列出自己项目适用的已发布或已关闭任务模板。
  - 草稿任务模板仅管理员可见。
- 修复 `GET /material-tasks/:taskId/templates/:attachmentId/download`：
  - 负责人只能下载自己项目适用的已发布或已关闭任务模板。
  - 下载前验证真实文件路径位于 `UPLOAD_ROOT`。
- 加固其他下载入口：
  - `GET /archive-exports/:id/download` 验证真实路径位于 `EXPORT_ROOT`。
  - 归档打包读取审核通过材料时验证真实路径位于 `UPLOAD_ROOT`，异常文件写入缺失报告。
  - `GET /import-templates/:type/download` 验证真实路径位于导入模板目录。
- 新增真实闭环脚本 `npm.cmd run check:owner-access`：
  - 自动创建两个不同项目、两个不同负责人、管理员、提交文件和任务模板。
  - 覆盖文件列表、文件下载、模板列表和模板下载的双向越权。
  - 覆盖管理员全局访问、负责人不可访问草稿模板、数据库目录外路径拒绝。
  - 如操作系统允许创建符号链接，会额外验证符号链接越界拒绝；本机本次因系统拒绝创建符号链接而跳过该小项。
  - 测试数据和临时文件在 `finally` 中清理。
