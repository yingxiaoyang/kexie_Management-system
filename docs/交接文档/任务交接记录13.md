# 科研项目材料管理平台任务交接记录

## 2026-08-07：对话 13 - 项目数据报表设计器

## 当前结论

对话 13 已完成第一版“项目数据报表设计器”。管理员可在网页模拟 Excel 网格中设计一个项目区块，保存为可复用方案，或仅按当前设计发起一次导出。报表导出不依赖上传固定 Excel 文件，不支持 Word，不使用 AI Agent，Excel 生成继续使用 `exceljs`，未重新引入 `xlsx`。

第一版支持两种 Excel 输出：

- 全部项目连续排列在同一个工作表。
- 每个项目生成一个独立工作表。

## 配置结构

新增独立表，不把报表设计配置塞进归档模板表：

- `report_designs`：保存方案名称、状态、创建人和 `design_config`。
- `report_export_records`：保存导出人、范围、设计快照、布局、队列状态、文件路径、失败原因、尝试次数和时间。

`design_config` 第一版结构：

```json
{
  "version": 1,
  "sheet": {
    "rowCount": 14,
    "columnCount": 8,
    "rows": [{ "index": 5, "height": 24 }],
    "columns": [{ "index": 1, "width": 18 }]
  },
  "cells": [
    {
      "row": 1,
      "col": 2,
      "value": "",
      "fieldKey": "project.code",
      "fieldMode": "single",
      "style": {
        "bold": true,
        "fontSize": 11,
        "color": "172033",
        "fill": "EAF2FF",
        "align": "center",
        "wrap": true,
        "border": true
      }
    }
  ],
  "merges": [
    { "startRow": 5, "startCol": 1, "endRow": 6, "endCol": 1 }
  ],
  "repeatRegions": [
    { "id": "members", "type": "members", "startRow": 5, "endRow": 6, "emptyMode": "noneText" }
  ],
  "export": {
    "layout": "continuous",
    "gapRows": 1,
    "sheetNameRule": "{项目编号}-{作品名称}"
  }

```

字段库由后端统一返回，分为项目信息、负责人、项目成员、指导老师、检查记录、报销信息和材料信息。项目成员、指导老师、检查记录和材料信息可作为重复区域逐行展开，也可在单元格中按汇总或换行模式渲染。

多条数据单元格支持额外配置：

- `itemTemplate`：每条数据的显示模板。自 2026-08-19 的兼容升级起，项目成员应写 `{项目成员.姓名}（{项目成员.学号}）`；旧 `{姓名}（{学号}）` 只会在绑定集合上下文明确时自动规范化。
- `itemSeparator`：条目之间的间隔符，例如 `、`、`；`、`,`、空格或换行。
- `emptyText`：没有数据时在该单元格显示的文字，例如 `无`。

如果不配置这些字段，旧方案继续按原规则渲染：单格汇总默认使用 `、`，单格换行默认使用换行符。

## 重复区域算法

后端生成 Excel 时按原始项目区块从上到下扫描：

1. 固定行直接复制一次。
2. 遇到重复区域时，按该区域绑定的数据集合复制区域内一行或多行模板。
3. 多个重复区域只按上下顺序分别展开，不进行笛卡尔积。
4. 没有数据时按配置处理：
   - `blank`：不生成该区域行。
   - `noneText`：保留一份区域并在对应字段显示“无”。
   - `keepBlank`：保留一份空白区域。
5. 重复区域展开后，下方内容整体顺延。

动态合并规则：如果重复区域内存在项目固定字段或负责人/报销等固定字段，并且该字段所在单元格原本配置了纵向合并，导出时会将该合并范围扩展到本次重复区域实际高度。例如成员区域 2 行模板、2 位成员时，项目编号所在单元格会随展开后的 4 行区域纵向合并。

## 预览差异

网页预览和实际 Excel 都使用同一套后端字段渲染与重复区域展开逻辑。差异主要在视觉层：

- 网页预览用于快速核对字段、行数和展开顺序，不完全模拟 Excel 的分页、打印、字体测量和合并单元格显示细节。
- 实际 Excel 会写入行高、列宽、字体、字号、颜色、背景色、边框、对齐、自动换行和合并区域。
- 工作表名称的非法字符、超长和重名处理只在实际导出时完整体现。

## 导出示例

连续排列：

```text
项目报表.xlsx
└─ 工作表：项目报表
   ├─ 项目 A 区块
   ├─ 空白分隔行
   ├─ 项目 B 区块
   └─ 项目 C 区块
```

每项目独立工作表：

```text
项目报表.xlsx
├─ 工作表：CX2026-001-零成员项目
├─ 工作表：重复_非法_超长项目名称用于验证工作表名称截断与重名处理___
└─ 工作表：重复_非法_超长项目名称用于验证工作表名称截断与重名处理__2
```
