## 配置说明

开发环境默认值：

```text
TRUST_PROXY=false
REQUEST_BODY_LIMIT=256kb
LOGIN_RATE_LIMIT_WINDOW_MINUTES=15
LOGIN_RATE_LIMIT_MAX=20
ADMIN_LOGIN_RATE_LIMIT_MAX=10
ACCOUNT_LOCK_MINUTES=15
ADMIN_ACCOUNT_LOCK_MINUTES=30
```

本地前后端直接访问时保持 `TRUST_PROXY=false`。生产由同机 Nginx/Caddy 反向代理时建议设置：

```text
TRUST_PROXY=loopback
```

生产 `CORS_ORIGINS` 必须是精确 HTTPS Origin，不带路径和尾斜杠，例如：

```text
CORS_ORIGINS=https://portal.example.edu.cn
```

不要设置 `TRUST_PROXY=true`，否则攻击者可能伪造转发链中的客户端 IP，绕过按 IP 限流。
