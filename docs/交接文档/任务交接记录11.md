# 科研项目材料管理平台任务交接记录

## 2026-08-06：对话 11 - 替换存在高危漏洞的 Excel 依赖

## 当前结论

对话 11 已完成。后端已完全移除存在高危安全公告的 `xlsx` 依赖，改用 `exceljs` 处理标准工作簿导入解析、归档导出材料清单和缺失材料报告生成。`npm audit --omit=dev` 最终结果为 `found 0 vulnerabilities`，生产依赖中不再保留高危漏洞。

## 已完成

- 依赖替换：
  - 从 `server\package.json` 和 `server\package-lock.json` 移除 `xlsx`。
  - 新增 `exceljs@4.4.0`。
  - 使用 `overrides` 将 `uuid` 固定到已修复的 `^11.1.1`，避免 `exceljs` 间接依赖触发中危审计公告。
- Excel 导入改造：
  - `POST /imports/standard-workbook/validate` 改为使用 `exceljs` 读取 `.xlsx`。
  - 保持 5 张业务表名称、字段名、必填规则、枚举规则、重复校验和跨表引用校验不变。
  - 学号、工号、项目编号、人员编号、电话和 QQ 均按文本读取，避免科学计数法或前导零丢失。
  - 增加 Excel 安全限制：文件最大 20MB、工作表最多 10 张、总行数最多 50000 行、单表最多 80 列。
  - 明显非 `.xlsx` 文件、空工作簿或解析失败统一返回 `VALIDATION_ERROR` 和“无法读取 Excel 工作簿”，不向接口响应暴露服务器堆栈。
- 归档导出改造：
  - `导出材料清单.xlsx` 改为由 `exceljs` 生成。
  - `缺失材料报告.xlsx` 改为由 `exceljs` 生成。
  - 导出表内单元格统一按文本格式写入，负责人电话、项目编号等字段保持文本。
- 下载路径回归加固：
  - `resolveDownloadFile` 在检查文件是否存在前，先拒绝目录外绝对路径或相对越界路径。
  - 避免数据库中写入目录外但不存在的路径时返回 404，从而绕过“目录外路径应被拒绝”的安全语义。
- 标准导入模板兼容：
  - 发现原标准模板可被 Excel 打开，但 XML 使用 `x:` 命名空间前缀，`exceljs` 无法读取。
  - 已用 `exceljs` 按原 CSV 字段和说明重新生成同名模板：
    `server\templates\import\科研项目数据标准导入模板.xlsx`
  - 新模板继续包含 `导入说明`、5 张业务表和 `字段字典`，并保留枚举下拉和文本列格式。
- 新增验证脚本：
  - `npm.cmd run check:excel`：不依赖数据库，验证标准模板可读、文本字段导入、工作簿限制、中文材料清单和缺失报告导出。
  - `npm.cmd run check:import-excel`：临时启动当前后端应用，验证标准模板接口预检、错误清单下载、坏文件安全报错。
  - `npm.cmd run build:import-template`：按 CSV 模板重新生成标准 XLSX 导入模板。
