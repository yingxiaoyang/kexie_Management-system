## 完成内容

- 新上传的材料和任务模板文件名会先做可验证的 UTF-8/Latin-1 纠错，再以 UTF-8 保存数据库。旧记录仅在字节往返和中文特征均可确认时显示修复名；不确定时原样显示并给出提示。
- 单文件下载使用 ASCII `filename` 回退和 RFC 5987 UTF-8 `filename*`；材料审核下载、项目工作台下载和任务模板下载均使用同一策略。
- PNG、JPEG、PDF 在网页内预览，后端同时校验扩展名、MIME 与文件头签名，并设置 `inline` 和 `nosniff`。Office、ZIP 及不匹配文件明确提示下载，不依赖任何公网转换服务。
- 审核列表支持多选提交记录并流式下载原始文件 ZIP。ZIP 不使用归档模板，不产生整理包；目录段清理路径字符、限制长度、保留中文、同名加序号，所有源路径继续受上传根目录和真实路径校验。
- 超级管理员可按未分配/已分配、审核人、状态、项目、材料任务和关键词筛选，可批量分配给有效、启用且拥有 `material_review` 的小管理员。改派必须填写原因。
- 小管理员列表由后端固定限制为 `assigned_to=当前用户`，无抢单接口；文件、预览、历史、批量下载和审核也重复校验当前受派人。
- 审核事务使用 `SELECT ... FOR UPDATE`、`review_status='pending'` 条件更新和 `assignment_version`。重复审核或改派后的旧页面提交返回 HTTP 409 中文冲突提示。
- `reviewed_by/reviewed_at/review_status/return_reason` 保存实际审核人、时间、结论和退回原因；实际审核人只能是当前受派人或超级管理员。
- 分配、改派、审核通过和退回写入不可变 `material_review_audit_events`，并聚合到项目工作台材料时间轴。工作台材料版本同时显示分配人、受派人和实际审核人。

## API

- `GET /api/submissions`：超级管理员全量筛选；小管理员仅本人受派任务。
- `GET /api/submissions/review-options`：超级管理员取得合法受派人及筛选选项。
- `POST /api/submissions/batch-assign`：原子批量分配/改派，带期望分配版本。
- `PATCH /api/submissions/:id/review`：带 `assignmentVersion` 的通过/退回。
- `GET /api/submissions/:id/audit`：不可变分配与审核历史。
- `GET /api/submissions/:id/files`：文件名兼容和预览能力信息。
- `GET /api/submissions/:submissionId/files/:fileId/preview`：安全内联预览。
- `GET /api/submissions/:submissionId/files/:fileId/download`：单文件原件下载。
- `POST /api/submissions/batch-download`：所选提交的原文件 ZIP。

详细请求字段与冲突语义见 `docs/接口契约/后端接口契约初稿.md`，物理字段见 `docs/系统字段字典.md`。
