### 后端对话需要知道

- 后端连接主机使用 `127.0.0.1`，端口 `3306`。
- 数据库名为 `kexie_db`，应用用户为 `kexie_user`。
- 密码从 `database\.env.mysql` 读取，不要硬编码到源代码。
- 后端启动前应确认 Docker Desktop 已运行，并确认 `kexie-mysql` 为 `healthy`。
- 后端直接运行在 Windows 上时使用 `DB_HOST=127.0.0.1`、`DB_PORT=3306`。
- 后端以后如果运行在同一 Docker Compose 网络内，应使用 `DB_HOST=mysql`、`DB_PORT=3306`，不能使用容器自身的 `127.0.0.1`。
- 当前数据库仅完成环境初始化，尚未创建业务表；业务数据模型由后端与数据库模型任务负责。

### GitHub 与新电脑恢复说明

- 应提交 `database\docker-compose.mysql.yml` 和 `database\mysql.env.example`。
- 不提交 `database\.env.mysql`、`database\mysql-data` 和 `database\backups`。
- 从 GitHub 克隆后，需要将 `mysql.env.example` 复制为 `.env.mysql`，填写新的本机密码，再运行 Compose。
- 本机数据库密码和已有数据不会通过 GitHub 自动同步；需要共享数据时应使用经过确认的数据库备份文件。
- 完整操作见 `docs\Docker与MySQL环境安装配置及运行维护说明.md`。
