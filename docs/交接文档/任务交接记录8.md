# 科研项目材料管理平台任务交接记录

## 2026-08-06：对话 8 - 账号凭证立即失效机制

## 当前结论

对话 8 已完成。账号删除、停用、锁定、重新启用、修改密码、管理员重置密码和退出时都会更新账号会话版本；旧 JWT/Cookie 在下一次请求时立即失效。浏览器登录已迁移为 HttpOnly Cookie，前端不再把 JWT 或用户信息写入 `localStorage`。

后端不再只校验 JWT 签名。每个受保护请求都会查询数据库，确认账号仍存在、未软删除、状态为启用，并校验数据库角色和 `token_version` 与 JWT 一致。

## 已完成

- 新增迁移 `005_user_token_version.sql`，为 `users` 增加 `token_version INT UNSIGNED NOT NULL DEFAULT 0`。
- 登录 JWT 写入 `tokenVersion`，并通过 `kexie_session` Cookie 交付浏览器。
- Cookie 始终启用 `HttpOnly`、`SameSite=Strict` 和 `/api` 路径；`NODE_ENV=production` 时自动启用 `Secure`。
- 前端所有 API 和下载请求使用 `credentials: include`，不再生成 `Authorization` 请求头，也不再访问 `localStorage`。
- `requireAuth` 每次请求查询 `users`，校验账号存在、`deleted_at IS NULL`、`status=enabled`、角色和版本一致。
- `password_reset_required=1` 时，后端只允许本人信息、修改密码和退出接口，其他接口返回 `PASSWORD_CHANGE_REQUIRED`。
- 修改密码后递增 `token_version`，同时签发新版本 Cookie，使当前改密流程可继续进入系统，其他旧会话立即失效。
- 账号状态变更和管理员重置密码时递增 `token_version`。
- 新增 `DELETE /api/accounts/:id` 软删除接口和管理员页面删除入口；软删除会停用账号、写入 `deleted_at` 并递增版本。
- 新增 `POST /api/auth/logout`；退出会递增版本并清除 Cookie，退出前凭证不可重放。
- 账号管理页禁止停用或删除当前管理员本人。
- 已更新旧归档检查脚本，使其生成包含 `tokenVersion` 的短期 Bearer JWT；浏览器业务流程仍只使用 Cookie。

## 兼容与部署注意事项

- 本地 HTTP 开发环境不会设置 `Secure`，否则浏览器无法向 `http://127.0.0.1` 发送 Cookie；生产环境设置 `NODE_ENV=production` 后自动启用。
- 生产环境必须通过 HTTPS，并保持前后端在满足 `SameSite=Strict` 的同站点部署结构中。
- 后端暂时保留带 `tokenVersion` 的 Bearer JWT 读取能力，供内部检查脚本和过渡客户端使用；登录接口不再把 JWT 返回给浏览器 JavaScript。
- 本次只完成会话立即失效和 Cookie 迁移；登录限流、失败锁定、Helmet、生产密钥/CORS 启动检查属于对话 9。
- 每次认证请求增加一次 `users` 表查询，这是本任务要求的即时状态校验；后续如做性能优化，不得缓存到无法立即反映停用或版本变化的程度。
