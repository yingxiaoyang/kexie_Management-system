# 后端运行说明

## 项目位置

后端基础服务位于：

```text
D:\kexiexitong\server
```

数据库初始化脚本位于：

```text
D:\kexiexitong\database\migrations\001_init.sql
```

## 运行前准备

本任务不负责 Docker 安装。运行后端前，需要先确认：

- Docker Desktop 已启动。
- MySQL 容器 `kexie-mysql` 已运行。
- 数据库名为 `kexie_db`。
- 应用用户为 `kexie_user`。
- 数据库密码从 `D:\kexiexitong\database\.env.mysql` 读取。

## 启动步骤

```powershell
cd D:\kexiexitong\server
Copy-Item .\.env.example .\.env
npm.cmd install
npm.cmd run db:init
npm.cmd run dev
```

`server\.env` 至少需要修改：

```text
DB_PASSWORD=<database\.env.mysql 中的 MYSQL_PASSWORD>
JWT_SECRET=<较长随机字符串>
INITIAL_ADMIN_PASSWORD=<管理员初始密码>
```

## 验证方式

访问：

```text
http://127.0.0.1:3000/api/health
```

正常返回示例：

```json
{
  "success": true,
  "code": "OK",
  "message": "ok",
  "data": {
    "service": "kexie-server",
    "status": "ok",
    "database": "connected"
  }
}
```

## 前后端跨域

后端默认允许：

```text
http://127.0.0.1:5173
http://localhost:5173
```

前端默认接口地址：

```text
VITE_API_BASE_URL=http://127.0.0.1:3000/api
```

```text

```

该目录属于本地运行数据，不提交 GitHub。
