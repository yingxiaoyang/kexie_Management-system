# 后端运行说明

## 项目位置

后端基础服务位于：

```text
D:\kexiexitong\server
```

数据库迁移脚本位于：

```text
D:\kexiexitong\database\migrations
```

`npm.cmd run db:init` 会创建 `schema_migrations` 记录表，并依次执行尚未应用的迁移。已初始化数据库的归档导出扩展使用 `002_archive_export_audit.sql`，不会重复执行已经记录的迁移。

## 运行前准备

本任务不负责 Docker 安装。运行后端前，需要先确认：

- Docker Desktop 已启动。
- MySQL 容器 `kexie-mysql` 已运行。
- 数据库名为 `kexie_db`。
- 应用用户为 `kexie_user`。
- 数据库密码从 `D:\kexiexitong\database\.env.mysql` 读取。

## 启动步骤

```powershell
cd D:\kexiexitong\server
Copy-Item .\.env.example .\.env
npm.cmd install
npm.cmd run db:init
npm.cmd run dev
```

`server\.env` 至少需要修改：

```text
DB_PASSWORD=<database\.env.mysql 中的 MYSQL_PASSWORD>
JWT_SECRET=<较长随机字符串>
INITIAL_ADMIN_PASSWORD=<管理员初始密码>
```

## 前后端跨域

后端默认允许：

```text
http://127.0.0.1:5173
http://localhost:5173
```

前端默认接口地址：

```text
VITE_API_BASE_URL=http://127.0.0.1:3000/api
```

## 本地文件存储

默认上传目录：

```text
D:\kexiexitong\storage\uploads
```

该目录属于本地运行数据，不提交 GitHub。

默认整理包导出目录：

```text
D:\kexiexitong\storage\exports
```

可在 `server\.env` 中通过下列变量调整：

```text
UPLOAD_ROOT=../storage/uploads
EXPORT_ROOT=../storage/exports
```

归档下载接口只允许管理员访问，并会验证下载文件仍位于 `EXPORT_ROOT` 内。

## 归档导出检查

后端语法与模块检查：

```powershell
cd D:\kexiexitong\server
npm.cmd run check
```

在后端服务已启动的情况下，可运行真实归档闭环检查：

```powershell
npm.cmd run check:archive
```

该检查会验证：

- 归档模板真实接口。
- 审核通过材料 ZIP 生成与管理员下载。
- 无审核通过材料时生成 `缺失材料报告.csv`。
- 项目负责人不能访问管理员归档接口。
- 导出目录外的下载路径会被拒绝。
- Windows 非法字符、路径穿越和重名序号处理。

检查会保留导出记录与 ZIP 便于人工查看；临时创建的缺失材料任务会在检查结束后删除。
