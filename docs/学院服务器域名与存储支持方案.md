# 科研项目管理平台服务器、域名与存储支持方案

更新日期：2026-08-07

## 一、项目规模与估算前提

当前系统第一届预计管理约 200 个科研项目，以后每年约 200 个项目。现阶段只用于科研项目管理，后续可能扩展到学院其他材料收取业务，但本方案暂不按后续扩展后的峰值采购。

当前系统包含 Vue 前端、Node.js 后端、MySQL 数据库、材料上传与审核、ZIP 归档导出和 Excel 报表导出。项目日常访问并发预计不高，但归档和报表导出会短时间占用较多内存、CPU 和磁盘空间。

容量估算采用以下区间：

- 每项目材料平均 100MB：约 20GB/年。
- 每项目材料平均 300MB：约 60GB/年。
- 加上历史版本、导出 ZIP、数据库备份和安全冗余后，实际准备空间按原始材料的 2 至 3 倍考虑，即约 60GB 至 180GB/年。
- 系统仍应设置单文件和单项目上限，并在第一年运行 3 个月后根据真实数据重新估算。

## 二、服务器与域名方案

### 方案 A：腾讯云服务器部署

#### 1. 推荐配置

| 使用阶段 | 配置 | 腾讯云官网当前标准价 | 建议 |
| --- | --- | ---: | --- |
| 最低试运行 | 2核2GB、50GB SSD、4Mbps、300GB/月流量 | 50元/月，510元/年 | 可以运行，但 Node、MySQL 和导出任务共用 2GB 内存，余量较小 |
| 当前推荐 | 2核4GB、100GB SSD、7Mbps、1000GB/月流量 | 100元/月，1020元/年 | 适合约 200 个项目的第一阶段正式试运行 |
| 后续扩展 | 4核8GB、180GB SSD、12Mbps、2000GB/月流量 | 245元/月，2499元/年 | 学院多个材料系统共同使用时再考虑 |

腾讯云当前活动页显示“4核4G新用户低至99元/年”，部分同价续费商品允许新购后同价续费一次。但活动资格、地域、库存、账号新客身份和续费次数均有限，学院长期预算应按官网标准价约 1020 元/年准备，活动价只作为实际采购时的节省机会。

推荐第一年选择：

- 符合活动资格时，优先购买 4核4GB 的 99 元/年活动套餐。
- 不符合活动资格时，购买 2核4GB、100GB SSD 套餐，按 1020 元/年预算。
- 正式资源应购买在学院或学校管理的单位腾讯云账号下，不建议长期放在学生个人账号中。
- 第一阶段 MySQL 可以与网站部署在同一台服务器，必须另外做数据库和材料备份。

#### 2. 自有域名和备案

自购域名不包含在服务器费用中。腾讯云轻量产品页显示域名 10 元起/首年，实际价格和续费价取决于 `.com`、`.cn` 等后缀。学院做年度预算时可按 60 至 100 元/年预留。单域名 DV HTTPS 证书可以使用腾讯云免费证书，官网当前标价为 0 元/年。

ICP 备案的作用是向通信管理部门登记网站主办单位、域名、服务内容和接入服务商。它不是域名注册，也不是网站内容审批，而是在中国内地通过互联网提供网站服务的法定登记手续。

根据腾讯云当前备案说明：

- 网站部署在中国内地服务器并对公网开放时，无论使用域名还是直接使用公网 IP，都应依法备案。
- 未完成 ICP 备案前不允许开通网站访问，提前开放可能被要求关闭或导致备案被驳回。
- 腾讯云备案初审通常为 1 至 2 个工作日，通信管理局审核在 20 个工作日内。
- 网站正式开通后，一般还应在 30 个自然日内办理公安联网备案。

不备案的可选做法是使用中国香港或境外服务器，但大陆访问延迟、网络稳定性、数据管理和学校合规性通常不如内地服务器，因此不推荐作为学院正式系统的长期方案。

#### 3. 腾讯云部署需要学院提供

- 确定以学校、学院还是其他单位作为系统责任主体。
- 提供或申请单位腾讯云账号，并明确续费负责人。
- 确定使用学校子域名还是新购独立域名。
- 如使用独立域名，提供单位备案所需证照、主体负责人和网站负责人资料。
- 明确系统管理员、数据负责人和离职或毕业后的账号交接人员。
- 确认服务器、域名、备案、备份和后续续费预算。

#### 4. 优缺点

优点：部署和远程维护方便；手机和校外访问方便；配置升级灵活；腾讯云提供快照、防火墙、监控和对象存储等配套服务。

缺点：需要持续付费；使用内地域名网站需要备案；云账号、域名和数据权限必须由学校长期接管；需要自行进行安全更新、监控和备份。

### 方案 B：学校服务器与学校域名部署

#### 1. 学校域名是否必须使用学校服务器

不必须。学校可以分配一个子域名，例如 `kyxm.example.edu.cn`，然后通过 DNS 的 A 记录或 CNAME 记录指向腾讯云服务器。因此可以组合成：

- 学校域名 + 学校服务器。
- 学校域名 + 腾讯云服务器。

但如果学校域名对应的网站实际托管在腾讯云内地服务器，学校信息化部门仍需确认备案主体、备案服务或接入备案要求。学校已有域名备案不代表可以在未经学校同意的情况下自行把子域名指向校外服务器。

#### 2. 使用学校域名需要学校提供

- 一个正式子域名及长期使用授权。
- DNS 解析配置，由学校将子域名指向服务器公网 IP 或反向代理地址。
- HTTPS 证书：可以由学校提供通配符证书，也可以配合 DNS 验证申请独立免费证书。
- 确认该子域名对应服务是否需要新增备案信息、接入备案或学校内部登记。
- 明确网站名称、主办单位、系统负责人和安全联系人。
- 如果学校要求统一登录、统一门户或校园网访问控制，需要提供相关接口和技术规范。

#### 3. 使用学校服务器需要学校提供

建议最低资源为 2核4GB，推荐提供：

- 4 vCPU、8GB 内存的 Linux 虚拟机。
- 至少 100GB 系统盘；材料不使用独立存储时还需另配 500GB 数据空间。
- Ubuntu 22.04/24.04 LTS 或学校统一支持的 Linux 系统。
- Docker、反向代理和数据库的安装权限，或者由学校运维人员代为部署。
- 公网 IP、学校统一反向代理或其他能够让手机和校外网络访问的入口。
- 开放 80/443，后台数据库端口不对公网开放。
- SSL 证书、防火墙规则、日志、监控、系统补丁和备份支持。
- 明确服务器故障、证书到期和紧急安全问题的联系人员及处理时限。

如果学校服务器只允许校园网访问，则手机使用移动网络或校外网络仍然打不开系统。需要学校提供公网反向代理、校园 VPN 或统一访问网关。

#### 4. 优缺点

优点：域名和数据归属清晰；可能不需要学院单独支付服务器费用；更符合学校统一安全和数据管理要求；与学校网盘、统一身份认证和校园网资源连接更方便。

缺点：部署权限和处理速度取决于学校信息化部门；没有服务器管理员权限时，每次更新都可能需要申请；校外访问、端口、证书和网络策略需要学校配合；学校服务器资源不足时扩容不如公有云灵活。

### 服务器与域名推荐结论

第一推荐是“学校域名 + 学院或学校单位腾讯云账号下的腾讯云服务器”。它兼顾学校身份和部署便利，但必须由学校授权域名并协调备案。

如果学校能及时提供满足配置要求、允许 Docker 部署并支持公网 HTTPS 访问的服务器，则“学校域名 + 学校服务器”在长期费用和数据管理上更合适。

不建议使用“学生个人腾讯云账号 + 学生个人域名”作为正式长期方案，因为毕业后会出现账号、备案主体、续费和数据所有权交接风险。

## 三、材料存储与备份方案

学校网盘通常只能提供文件存储，不能运行 Node.js 网站和 MySQL 数据库。除非学校提供的是可以安装程序的云主机或虚拟机，否则“把网站部署到网盘”不可行，但把材料和备份保存到网盘是可行的。

### 方案 A：COS 作为在线材料存储，学校网盘作为备份

#### 1. 使用方式

- 网站和数据库运行在腾讯云或学校服务器。
- 负责人上传的材料、任务模板和导出文件保存到腾讯云 COS。
- 数据库仍运行在服务器中，每日生成加密备份。
- 材料和数据库备份定时复制到学校网盘，形成云端在线存储与学校侧备份两份副本。

COS 使用 API 和 SDK，比较适合作为网站实时读写的在线存储。当前系统使用本地文件路径，接入 COS 时需要增加存储适配层，不能只把一个网盘文件夹地址填入配置。

#### 2. 腾讯云当前公开存储价格

| 类型 | 官网当前标价 | 适用方式 |
| --- | ---: | --- |
| 标准存储 | 0.099元/GB/月起 | 正在提交、审核和下载的材料 |
| 低频存储 | 0.08元/GB/月起 | 每月只访问约 1 至 2 次的历史材料，最低保存 30 天 |
| 归档存储 | 0.03元/GB/月起 | 长期备份，取回前需要恢复，最低保存 90 天 |
| 深度归档 | 0.01元/GB/月起 | 极少取回的长期备份，最低保存 180 天 |

仅按标准存储容量估算，不含请求次数、公网下行流量、数据取回和其他增值费用：

| 容量 | 每月存储费 | 每年存储费 |
| --- | ---: | ---: |
| 100GB | 约9.9元 | 约118.8元 |
| 200GB | 约19.8元 | 约237.6元 |
| 500GB | 约49.5元 | 约594元 |

实际费用还包含请求和网络流量。项目材料下载不频繁时，这部分通常可控，但正式预算建议按 300 至 800 元/年预留，并通过资源包和生命周期规则降低费用。新客 1 元等活动只作为采购优惠，不作为长期预算依据。

#### 3. 优缺点

优点：适合程序直接上传和下载；容量可以自动扩展；权限、HTTPS、生命周期和文件校验能力完整；腾讯云服务器访问同地域 COS 较方便。

缺点：需要改造当前本地存储代码；存在持续存储和流量费用；云账号和密钥必须由学校管理；学校网盘仍需承担第二份备份。

### 方案 B：服务器在线存储，学校网盘负责自动备份

#### 1. 使用方式

- 网站、数据库和近期材料先保存在服务器磁盘。
- 每日将数据库备份和新增材料同步到学校网盘。
- 每周生成完整备份，每月保留长期归档版本。
- ZIP 和 Excel 导出文件设置保存期限，过期自动清理，避免重复文件长期占用服务器空间。

该方案对当前系统改动较小。如果使用学校服务器，并且学校网盘支持 SMB 或 NFS，网盘也可以作为独立数据盘挂载。但不建议把普通网页网盘直接当作系统实时磁盘。

#### 2. 推荐学校网盘空间

按每年 200 个项目估算：

- 最低试运行空间：200GB，只适合第一年并严格清理导出文件。
- 当前推荐空间：500GB，可容纳第一年材料、多版本、数据库备份和一定历史余量。
- 更稳妥空间：1TB，适合保留 3 至 5 年科研项目数据，或为后续其他材料业务预留空间。

推荐向学校申请“初始 500GB、可扩容至 1TB”的专用空间。第一年运行后再根据每个项目真实平均大小调整。

#### 3. 学校网盘需要提供的技术条件

学校需要明确网盘是否支持以下至少一种自动访问方式：

- S3 兼容 API。
- WebDAV。
- SFTP。
- SMB 或 NFS 网络挂载。
- 学校自有开放 API。

同时需要提供：

- 专门的系统服务账号，不能使用某位学生的个人网盘账号。
- 服务器地址、协议、端口、目录和空间配额。
- 访问凭证的安全保管和定期更换方式。
- 单文件大小限制、每日流量限制、请求频率限制和禁止的文件类型。
- 回收站、历史版本、快照、误删恢复和数据保留规则。
- 数据校验方式，例如文件大小、SHA-256 或同步日志。
- 是否支持服务器 IP 白名单。
- 网盘是否只能校园网访问。
- 故障联系人、恢复时限和扩容流程。

如果网站部署在腾讯云，而学校网盘只能在校园网内部访问，腾讯云服务器无法直接备份。学校还需要提供公网 HTTPS/SFTP 接口、固定 IP 白名单、校园 VPN 或站点间安全隧道。

如果学校网盘只提供浏览器网页，没有 API、WebDAV、SFTP、SMB 或 NFS，则只能人工定期上传备份，不能作为可靠的自动备份方案。

#### 4. 推荐备份内容和周期

备份不能只保存上传文件，还应包括：

- MySQL 数据库备份。
- 负责人上传的全部材料和历史版本。
- 管理员上传的任务模板。
- 系统环境配置的脱敏副本。
- 数据库迁移文件和应用版本号。
- 必要的归档与报表设计配置。

建议周期：

- 每日：数据库备份和新增文件增量同步。
- 每周：完整数据库与文件校验。
- 每月：保留一个长期归档版本。
- 至少每学期：进行一次实际恢复演练，确认备份能够还原，而不只是文件存在。

## 四、存储推荐结论

如果选择腾讯云服务器，推荐“COS 保存在线材料 + 学校网盘保存数据库和材料备份”。这是扩展性和可靠性最好的方式，但需要增加 COS 存储适配。

如果选择学校服务器，推荐“学校服务器或挂载数据盘保存在线材料 + 学校网盘自动备份”。前提是学校提供稳定的数据盘、自动同步协议和恢复支持。

无论选择哪种方式，都不建议只保留一份材料；至少要有在线副本和独立备份副本，并确保备份账号、服务器和域名归学校或学院长期管理。

### 综合费用对比

| 综合方案 | 首年可预期费用 | 后续年度稳定预算 | 说明 |
| --- | ---: | ---: | --- |
| 学校域名 + 腾讯云服务器 + COS + 学校网盘备份 | 活动资格合适时约400至1000元；无活动约1320至1820元 | 约1320至1820元/年 | 按服务器1020元、COS及流量300至800元估算；学校子域名和免费证书不另计费 |
| 独立域名 + 腾讯云服务器 + COS + 学校网盘备份 | 在上一方案基础上增加约60至100元 | 约1380至1920元/年 | 还需要由单位办理备案和长期管理域名 |
| 学校域名 + 学校服务器 + 学校网盘 | 取决于学校内部资源，可能无对外采购费用 | 主要是学校运维和资源成本 | 最符合学校管理，但依赖学校提供公网入口、部署权限和及时运维 |

以上不包含短信、商业 SSL 证书、云数据库、高防、CDN 和专职运维等当前阶段不需要的服务。

## 五、建议学院本次确认的问题

### 服务器与域名

1. 学校能否提供可公网访问的 Linux 虚拟机？可提供多少 CPU、内存和磁盘？
2. 是否允许安装 Docker、Node.js、MySQL 和 Nginx，谁负责后续更新？
3. 能否分配学校子域名并配置 DNS 和 HTTPS 证书？
4. 学校子域名指向腾讯云服务器是否被允许，备案由哪个部门协助？
5. 如果使用腾讯云，能否建立学校或学院管理的单位云账号和年度续费预算？

### 网盘与备份

1. 能否提供初始 500GB、后续可扩容至 1TB 的系统专用空间？
2. 是否支持 S3、WebDAV、SFTP、SMB、NFS 或开放 API？
3. 腾讯云服务器能否访问该网盘，还是只能从校园网访问？
4. 能否提供长期服务账号、IP 白名单、版本恢复和扩容支持？
5. 学校是否有数据保留期限、加密、日志审计和敏感数据管理要求？
