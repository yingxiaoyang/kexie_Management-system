# 后端接口契约初稿

## 基础约定

接口前缀：

```text
http://127.0.0.1:3000/api
```

统一返回格式：

```json
{
  "success": true,
  "code": "OK",
  "message": "ok",
  "data": {},
  "pagination": {
    "page": 1,
    "pageSize": 20,
    "total": 100,
    "totalPages": 5
  }
}
```

失败返回：

```json
{
  "success": false,
  "code": "BAD_REQUEST",
  "message": "错误说明",
  "data": null
}
```

数据库表名、SQL、约束名和本地文件路径不通过接口返回。非预期服务端异常统一返回 `INTERNAL_ERROR`，详细错误只记录在本地服务日志中。

## 常用错误码

- `OK`：成功
- `BAD_REQUEST`：请求参数错误
- `UNAUTHORIZED`：未登录或登录过期
- `INVALID_CREDENTIALS`：账号或密码错误
- `FORBIDDEN`：无权限
- `NOT_FOUND`：资源不存在
- `ROUTE_NOT_FOUND`：接口地址不存在
- `VALIDATION_ERROR`：业务校验失败
- `DUPLICATE_RESOURCE`：重复数据
- `UPLOAD_TYPE_NOT_ALLOWED`：上传格式不允许
- `UPLOAD_FILE_SIZE_EXCEEDED`：单文件大小超限
- `UPLOAD_FILE_COUNT_EXCEEDED`：单次上传文件数量超限
- `UPLOAD_TOTAL_SIZE_EXCEEDED`：累计上传大小超限
- `DATABASE_UNAVAILABLE`：数据库不可用
- `INTERNAL_ERROR`：服务器内部错误

## 分页约定

列表接口统一使用：

```text
page=1&pageSize=20
```

默认：

- `page=1`
- `pageSize=20`
- 最大 `pageSize=100`

## 字段格式

时间：

- 日期：`YYYY-MM-DD`
- 日期时间：ISO 8601 字符串，例如 `2026-08-05T13:00:00.000Z`
- 前端展示时按 Asia/Shanghai 显示。

金额：

- 数据库存储为 `DECIMAL(12,2)`。
- 接口建议返回字符串，例如 `"3000.00"`，避免 JavaScript 浮点误差。

文件大小：

- 接口返回字节数，例如 `52428800`。

## 登录接口

### POST /auth/login

请求：

```json
{
  "username": "admin",
  "password": "ChangeMe123!"
}
```

响应：

```json
{
  "success": true,
  "code": "OK",
  "message": "ok",
  "data": {
    "token": "jwt-token",
    "user": {
      "id": 1,
      "username": "admin",
      "displayName": "系统管理员",
      "role": "admin",
      "status": "enabled",
      "personId": null,
      "passwordResetRequired": true
    }
  }
}
```

后续请求头：

```text
Authorization: Bearer <token>
```

### GET /auth/me

返回当前登录用户。

### POST /auth/change-password

请求：

```json
{
  "oldPassword": "old-password",
  "newPassword": "new-password"
}
```

- 首次登录或重置后必须改密。

## 文件上传接口

### POST /uploads/task-templates

管理员上传材料任务模板附件。

请求类型：`multipart/form-data`

字段：

- `taskId`：材料任务 ID
- `files`：一个或多个文件

限制：

- 单文件默认不超过 50MB。
- 单次最多上传 10 个文件。
- 支持 PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX、JPG、JPEG、PNG、ZIP。

### POST /uploads/submissions

负责人提交材料。

请求类型：`multipart/form-data`

字段：

- `taskId`：材料任务 ID
- `projectId`：项目 ID
- `categoryId`：材料类别 ID
- `files`：一个或多个文件

限制：

- 单文件默认不超过 50MB。
- 单次最多上传 20 个文件。
- 单个项目在一个材料任务下累计默认不超过 500MB。

## 导入模板下载接口

### GET /import-templates/:type/download

管理员下载导入模板。

`type` 可选：

- `standard-workbook`：推荐使用，包含全部 5 张标准数据表的 XLSX 工作簿
- `projects`
- `people`
- `participations`
- `checks`
- `reimbursements`

示例：

```text
GET /api/import-templates/projects/download
```

推荐下载完整工作簿：

```text
GET /api/import-templates/standard-workbook/download
```

## 标准工作簿导入接口初稿

完整导入分为“预检查”和“确认入库”两步，预检查不会修改数据库。

### POST /imports/standard-workbook/validate

请求类型：`multipart/form-data`

- `file`：标准 `.xlsx` 工作簿，最大 20MB

成功后返回临时批次编号和检查摘要：

```json
{
  "success": true,
  "code": "OK",
  "message": "校验完成",
  "data": {
    "batchId": "import-batch-id",
    "valid": false,
    "expiresAt": "2026-08-05T16:00:00.000Z",
    "sheets": [
      {
        "name": "1_项目",
        "totalRows": 100,
        "validRows": 98,
        "errorRows": 2
      }
    ]
  }
}
```

### GET /imports/:batchId/errors/download

下载预检查错误清单。每条错误包含工作表名称、Excel 行号、字段名、原值和错误原因。

### POST /imports/:batchId/commit

确认正式导入：

```json
{
  "mode": "create_only"
}
```

`mode` 可选：

- `create_only`：默认，仅新增；数据库已有唯一编号时拒绝导入。
- `upsert`：明确用于修正数据；已有数据按唯一编号更新，不存在的数据新增。

只有预检查全部通过的批次可以提交。提交过程使用数据库事务，失败时整批回滚。
