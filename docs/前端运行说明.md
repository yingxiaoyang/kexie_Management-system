# 前端运行说明

## 1. 项目位置

前端项目目录：

`D:\kexiexitong\code\kexie_vue`

技术栈：

- Vue 3
- Vite
- Vue Router
- Element Plus

## 2. 当前页面结构

入口页：

- `/`：角色入口与接口地址展示

项目负责人端：

- `/owner/dashboard`：负责人工作台
- `/owner/projects`：我的项目
- `/owner/submissions`：材料提交
- `/owner/contacts`：项目通讯录

管理员端：

- `/admin/dashboard`：管理总览
- `/admin/projects`：项目管理
- `/admin/people`：人员库管理
- `/admin/accounts`：账号管理
- `/admin/tasks`：材料任务
- `/admin/reviews`：材料审核
- `/admin/archive-templates`：归档模板
- `/admin/exports`：整理包导出
- `/admin/rules`：参与规则

页面文件目录：

- `src\views\owner`：项目负责人端页面
- `src\views\admin`：管理员端页面
- `src\router\index.js`：前端路由
- `src\config\api.js`：后端接口地址配置
- `src\data\mock.js`：仅剩参与规则等尚未接入页面的示例数据；归档模板和整理包导出已不再使用此文件

## 3. 本机启动

进入前端目录：

```bash
cd D:\kexiexitong\code\kexie_vue
```

安装依赖：

```bash
npm.cmd install
```

启动开发服务：

```bash
npm.cmd run dev
```

默认访问：

- `http://127.0.0.1:5173/`
- `http://127.0.0.1:5173/owner/dashboard`
- `http://127.0.0.1:5173/admin/dashboard`

构建验证：

```bash
npm.cmd run build
```

## 4. 后端接口地址

前端读取环境变量：

```bash
VITE_API_BASE_URL=http://127.0.0.1:3000/api
```

已新增：

- `.env.example`：可提交的环境变量示例
- `.env.development`：本机开发默认配置

如果后端端口变化，只需要修改 `.env.development` 中的 `VITE_API_BASE_URL`。

## 5. Element Plus 后台页面约定

管理员端统一使用：

- `el-table`：列表页主体，项目、人员、任务、审核、导出记录都走表格
- `el-input`、`el-select`、`el-date-picker`：列表筛选和表单字段
- `el-dialog`：新增、编辑、上传、退回原因等弹窗
- `el-form`：弹窗内表单
- `el-tag`：项目状态、审核状态、账号状态
- `el-upload`：负责人材料上传入口
- `el-switch` + `el-upload`：管理员为每个子文件任务分别决定是否提供模板，并上传对应模板文件

负责人材料提交列表已接入真实模板下载与材料提交接口。

## 6. 中文显示说明

`App.vue` 已从默认按钮页面替换为路由出口。当前源码以 UTF-8 保存，页面中文显示正常。

PowerShell 读取 UTF-8 文件时如果控制台编码不一致，可能会看到乱码；这不一定代表网页实际乱码。以浏览器页面和构建结果为准。

## 8. 对话 6 界面与响应式状态

负责人端已升级为门户式工作台，重点展示当前待办、退回原因、截止时间、材料完成度和负责项目。

管理员端继续使用高密度表格，并统一了侧栏、顶部栏、筛选区、分页、状态标签和弹窗样式。

响应式规则：

- 宽度大于 900px：显示固定侧栏和桌面顶部栏。
- 宽度不超过 900px：隐藏侧栏，使用顶部按钮打开抽屉导航。
- 宽度不超过 720px：负责人材料、项目、通讯录，以及管理员项目、人员、账号、任务、审核列表切换为卡片展示。
- 手机端弹窗限制在屏幕宽度内，内容区域可以独立滚动。

## 9. 对话 7 归档与导出页面

`/admin/archive-templates` 已接入真实接口，支持：

- 新建、编辑、启用和停用。
- 每个项目固定生成一个项目根目录，同一模板应用于全部筛选项目。
- 左侧资源管理器式递归目录树，可创建最多 8 层文件夹并上移、下移、拖放移动。
- 右侧按统筹任务分组展示子文件任务；桌面端可拖入目录，手机端可点“加入所选文件夹”。
- 子文件任务在一个模板内只允许放置一次，选中后可独立设置归档文件名。
- 可配置是否保留空文件夹。
- 归档字段选择面板按类别展示推荐字段，包含项目/材料序号、导出日期和批次、项目和负责人信息、团队信息、材料名称、原文件名及审核日期等字段，并支持搜索后点击插入。
- 保存前始终实时显示完整示例目录树和文件名。
- 桌面表格与手机卡片。

`/admin/exports` 已接入真实接口，支持：

- 按年度、组别、统筹任务和项目进行结构化筛选。
- 选择版本 2 模板后只显示该模板已经放置的统筹任务，并默认全选。
- 查看 `processing`、`success`、`failed` 状态。
- 自动轮询正在生成的记录。
- 查看材料数、缺失数和失败原因。
- 下载成功生成的 ZIP。
- 桌面表格与手机卡片。

两个页面继续复用管理员布局；手机端弹窗沿用全局内部滚动规则。

`/admin/tasks` 的创建弹窗已改为“统筹任务 + 子文件任务”结构。管理员可为每个子任务填写名称、提交说明、必交状态并调整顺序，还可分别设置允许格式、单文件大小、是否提供模板和对应模板文件。适用范围支持全部项目、指定年度、指定现有组别和多选指定项目，年度及组别选项会显示匹配项目数。

所有统筹任务都可以点击打开。未关闭且尚无提交记录时可编辑，包括已发布但还没有收到提交的任务；已有提交或已关闭时以只读方式查看。`/owner/submissions` 每个子任务一次只允许选择一个文件，并只显示该子任务对应的模板。

归档模板创建弹窗底部为实时目录预览：项目根目录、文件夹和文件命名规则变化会即时反映，不再使用容易误解的固定示例说明。整理包中的材料清单和缺失报告均为 `.xlsx` Excel 文件，缺失报告包含负责人电话。
