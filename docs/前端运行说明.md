# 前端运行说明

## 1. 项目位置

前端项目目录：

`D:\kexiexitong\code\kexie_vue`

技术栈：

- Vue 3
- Vite
- Vue Router
- Element Plus

## 2. 当前页面结构

入口页：

- `/`：角色入口与接口地址展示

项目负责人端：

- `/owner/dashboard`：负责人工作台
- `/owner/projects`：我的项目
- `/owner/submissions`：材料提交
- `/owner/contacts`：项目通讯录

管理员端：

- `/admin/dashboard`：管理总览
- `/admin/projects`：项目管理
- `/admin/people`：人员库管理
- `/admin/accounts`：账号管理
- `/admin/tasks`：材料任务
- `/admin/reviews`：材料审核
- `/admin/archive-templates`：归档模板
- `/admin/exports`：整理包导出
- `/admin/rules`：参与规则

页面文件目录：

- `src\views\owner`：项目负责人端页面
- `src\views\admin`：管理员端页面
- `src\router\index.js`：前端路由
- `src\config\api.js`：后端接口地址配置
- `src\data\mock.js`：当前页面示例数据，后续接后端接口后可替换

## 3. 本机启动

进入前端目录：

```bash
cd D:\kexiexitong\code\kexie_vue
```

安装依赖：

```bash
npm.cmd install
```

启动开发服务：

```bash
npm.cmd run dev
```

默认访问：

- `http://127.0.0.1:5173/`
- `http://127.0.0.1:5173/owner/dashboard`
- `http://127.0.0.1:5173/admin/dashboard`

构建验证：

```bash
npm.cmd run build
```

## 4. 后端接口地址

前端读取环境变量：

```bash
VITE_API_BASE_URL=http://127.0.0.1:3000/api
```

已新增：

- `.env.example`：可提交的环境变量示例
- `.env.development`：本机开发默认配置

如果后端端口变化，只需要修改 `.env.development` 中的 `VITE_API_BASE_URL`。

## 5. Element Plus 后台页面约定

管理员端统一使用：

- `el-table`：列表页主体，项目、人员、任务、审核、导出记录都走表格
- `el-input`、`el-select`、`el-date-picker`：列表筛选和表单字段
- `el-dialog`：新增、编辑、上传、退回原因等弹窗
- `el-form`：弹窗内表单
- `el-tag`：项目状态、审核状态、账号状态
- `el-upload`：负责人材料上传入口

后续接接口时建议保持这个页面形态，只替换数据来源和提交动作。

## 6. 中文显示说明

`App.vue` 已从默认按钮页面替换为路由出口。当前源码以 UTF-8 保存，页面中文显示正常。

PowerShell 读取 UTF-8 文件时如果控制台编码不一致，可能会看到乱码；这不一定代表网页实际乱码。以浏览器页面和构建结果为准。
