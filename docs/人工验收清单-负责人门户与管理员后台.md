# 负责人门户与管理员后台人工验收清单

适用范围：对话 6 的负责人门户、管理员表格页、材料任务页、材料审核页，以及桌面端和手机端响应式界面。

## 一、验收准备

- [ ] Docker Desktop 已启动，MySQL 容器状态正常。
- [ ] 后端健康检查 `http://127.0.0.1:3000/api/health` 返回成功。
- [ ] 前端可访问 `http://127.0.0.1:5173/login`。
- [ ] 准备一个已完成首次改密的项目负责人账号。
- [ ] 准备一个已完成首次改密的管理员账号。
- [ ] 数据库中至少有一个项目、一个材料任务和一条提交记录，便于检查真实状态。

## 二、推荐验收尺寸

桌面端：

- [ ] 1440 × 900。
- [ ] 1366 × 768。
- [ ] 浏览器缩放保持 100%。

手机端：

- [ ] 390 × 844，代表常见手机宽度。
- [ ] 360 × 800，检查更窄屏幕。
- [ ] 页面没有整体横向滚动条。

## 三、负责人端桌面验收

### 负责人工作台

- [ ] 左侧导航固定显示，当前菜单高亮明确。
- [ ] 顶部显示当前负责人姓名，可正常退出登录。
- [ ] 首屏展示问候语、当前材料提示和主要操作入口。
- [ ] 项目数、待提交、退回待处理、等待审核四项指标与真实数据一致。
- [ ] 材料完成度只按“已通过 / 全部材料任务”计算。
- [ ] 退回材料优先于未提交材料展示。
- [ ] 退回原因醒目可读，重新提交入口明确。
- [ ] 我的项目卡片可显示项目编号、名称、组别和指导老师。
- [ ] 空数据时显示友好空状态，不出现空白大表格或报错。

### 材料提交页

- [ ] 顶部统计与任务列表状态一致。
- [ ] 可按任务、项目、材料类别搜索。
- [ ] 可按未提交、待审核、已通过、已退回筛选。
- [ ] 有模板时可打开模板列表并下载。
- [ ] 已通过或待审核材料的提交按钮被正确禁用。
- [ ] 已退回材料显示审核意见，按钮文案为“重新提交”。
- [ ] 上传弹窗显示项目、任务、大小限制和允许格式。
- [ ] 上传成功后列表状态会刷新。

### 我的项目与项目通讯录

- [ ] 只展示当前负责人关联的项目。
- [ ] 通讯录只能选择本人负责的项目。
- [ ] 联系人搜索可匹配姓名、学院或单位、电话、QQ、邮箱。
- [ ] 电话、QQ、邮箱缺失时显示清晰的空值，不破坏表格布局。

## 四、管理员端桌面验收

### 管理总览

- [ ] 左侧菜单分区清楚，九个后台入口均可访问。
- [ ] 项目、人员、待审核材料、材料任务指标与数据库一致。
- [ ] 待审核材料和最近任务在空数据与有数据时均能正常显示。
- [ ] “新建材料任务”“进入审核”“任务管理”入口可用。

### 管理员表格页

- [ ] 项目、人员、账号列表表头、筛选区、操作列层级清楚。
- [ ] 搜索框和筛选器不会挤压主要操作按钮。
- [ ] 固定操作列不会覆盖状态或其他核心字段。
- [ ] 长项目名称和长材料名称不会撑破布局。
- [ ] 分页位于表格底部右侧，页码切换后数据正常刷新。
- [ ] 新增、编辑弹窗在桌面端居中，字段标签对齐。

### 材料任务页

- [ ] 当前列表、收集中、草稿、本页待审核统计正常。
- [ ] 可按任务名称和任务状态筛选。
- [ ] 草稿显示编辑和发布操作。
- [ ] 收集中显示关闭操作，已关闭显示重新开放操作。
- [ ] 新建任务弹窗可配置范围、材料类别、截止时间、格式和大小。
- [ ] 提供模板开关开启后显示多文件选择入口。
- [ ] 保存草稿和创建并发布不会被弹窗内容遮挡。

### 材料审核页

- [ ] 默认进入待审核筛选。
- [ ] 待审核、已通过、已退回、全部四个筛选可切换。
- [ ] 项目、任务、材料类别、提交人、时间、文件、状态和操作列均可见。
- [ ] 可打开提交文件列表并下载文件。
- [ ] 待审核记录显示通过和退回操作。
- [ ] 退回原因少于 4 个字符时不能提交。
- [ ] 审核完成后列表和统计会刷新。

## 五、手机端验收

### 通用布局

- [ ] 左侧菜单隐藏，顶部显示菜单按钮、页面标题和用户首字。
- [ ] 点击菜单按钮后从左侧打开抽屉导航。
- [ ] 点击菜单项后抽屉自动关闭并完成跳转。
- [ ] 页面主内容左右留白适中，没有整体横向滚动。
- [ ] 页面标题、说明和主按钮按纵向排列，主按钮可单手点击。

### 负责人端

- [ ] 工作台欢迎区在手机端隐藏次要进度卡，保留核心提示和两个入口。
- [ ] 四个指标以两列卡片展示，文字不重叠。
- [ ] 材料提交页由桌面表格切换为卡片列表。
- [ ] 每张材料卡可看到项目、类别、截止时间、状态和审核反馈。
- [ ] 下载模板和提交按钮在卡片底部清晰可用。
- [ ] 我的项目和项目通讯录切换为卡片，不要求横向拖动表格。

### 管理员端

- [ ] 项目、人员、账号、材料任务、材料审核列表切换为卡片。
- [ ] 卡片保留桌面表格中的核心字段和主要操作。
- [ ] 筛选控件占满可用宽度，不出现被裁切的下拉框。
- [ ] 审核状态按钮允许自然换行，仍可准确点击。
- [ ] 新建任务弹窗宽度适配手机，内容区域可独立滚动。
- [ ] 弹窗底部取消、保存草稿、创建并发布按钮始终可见。
- [ ] 审核文件弹窗和退回弹窗不超出屏幕。

## 六、异常与可访问性检查

- [ ] 接口加载时显示加载状态，不允许重复触发主要操作。
- [ ] 接口失败时显示中文错误提示，页面不白屏。
- [ ] 空列表显示空状态文案。
- [ ] 所有主要按钮有清晰文字，不只依赖图标表达含义。
- [ ] 状态不只依赖颜色，同时显示“未提交、待审核、已通过、已退回”等文字。
- [ ] 浏览器控制台无红色错误。
- [ ] 刷新当前路由后登录状态和角色权限仍正确。
